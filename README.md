# AIdentify multi-page landing site

Static HTML/CSS/JS, no build step. Open `index.html` in a browser, or run `npx serve .` / `python3 -m http.server`.

| Menu item | Page |
|---|---|
| Home | index.html |
| Why AIdentify | why-aidentify.html |
| Benefits | benefits.html |
| How it works | how-it-works.html |
| Who it's for | who-its-for.html |
| Features | features.html |
| FAQ | faq.html |
| Get Started / Sign in | get-started.html |
| Privacy / Terms / Delete my data | privacy.html, terms.html, deletion.html |

Sign-up/sign-in is a front-end placeholder: point the form in `get-started.html` at your real endpoint.
